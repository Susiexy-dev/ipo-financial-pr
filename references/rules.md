# 规则、时效与证据基线

## 使用方法

基线核验日2026-09-11。下列为已取得的部分官方依据和仍须逐案核实的规则目录，不是全量法规审查结论。搜索摘要、网页更新时间和发布日期可能不一致，以正文及实施条款为准。“最新规则”任务再查修订、生效、过渡和适用例外。

记录规则ID、市场/板块/主体、文件全称与条号、发布日、生效/失效日、核验日、原文URL及定位、支持的结论、适用条件、项目对应、例外、待核项。区分正式规则、监管解释、咨询稿、执行观察、机构观点；不用咨询稿宣布已落地。

来源优先：监管/交易所和正式披露；行业原始资料；可靠媒体独立报道；其他二手信息作线索。媒体报道可分析媒体视角，不直接代替公司事实。转载同源不算多重核实。搜不到不等于不存在。

## 对外行为核验

逐项核市场、主体、阶段、信息状态、受众/地区、载体、内容及公开时点。内部起草不等发布审核。

| 行为 | 核验重点 | 处理 |
| --- | --- | --- |
| 正常经营/产品新闻 | 是否偏离既有惯例、含发行推介、新财务/前瞻信息 | 按实际宣传规则核查，不一律停发或放行 |
| 媒体回应 | 是否公开、是否增加重大信息、是否须更新披露 | 先核事实，再定回应与披露先后 |
| 递表/过会/聆讯/上市稿 | 状态证据、宣传限制、审阅/警示和地区 | 先备草稿，满足条件后发布 |
| 采访/路演/KOL | 受众资格、销售限制、未披露预测、误导招揽 | 采访不绕过发行宣传要求 |
| 定价/基石/认购解释 | 正式文件、真实分母、收益保证风险 | 讲机制和风险，不制造“稳赚”预期 |

## 时间管理

每一期限记录法源与版本、触发事件、日历日/工作日/交易日、起算方式、暂停/排除、负责人及复核状态。内部T-7或两小时响应目标是管理安排。港股申请有效期、财务材料有效性与境内备案进度分别跟踪，不能相互替代。

# IPO事件场景卡

## 共同执行方法

先选一张主卡，再叠加市场阶段卡；不要一次输出全部卡。每次落地都写明：触发条件、已知事实/未知、受影响者、影响与优先级、策略、牵头及协同、时限、交付及验收、后续观察。用户只需短答时按比例压缩。

内部响应目标按严重性与团队覆盖设置。可建议紧急事项即刻通知协调人、当班完成初核及任务分配，后续滚动复核；不是法定时限或“两小时消除负面”承诺。对外时间取决于事实、披露要求及审定，必要业务行动不等口径写好。

## 事实、媒体与经营事件

| 卡/触发 | 分析与决策 | 动作、责任及产出 | 验收和切换 |
| --- | --- | --- | --- |
| S01 专业媒体求证/财务质疑 | 拆开具体指控、数据期间、引用版本及意见；判断错误、合理疑问、未披露信息或真实问题 | PR接收问题和截止时点；财务/业务逐项核；法务/保荐评披露；制作证据对照、回复草案、未答原因 | 每题有事实/出处和责任人；真问题转整改，不能只改措辞 |
| S02 匿名举报/员工客户投诉 | 来源匿名不代表内容虚假；核事项、法律程序、影响主体及是否已公开 | 法务/HR/业务牵头，保全材料、访谈核实、保护个人资料；PR准备分受众口径；保荐人处理监管接口 | 不称“黑函”定罪，不报复；有真实损害优先处理与整改 |
| S03 疑似索财/有偿删稿 | 收费威胁与文章事实分别判断，商业推销不自动构成犯罪 | 法务保存原始联系和付款要求、核身份、评估投诉/报案；PR继续核事实、准备证据支持的更正请求 | 不支付换沉默，不威胁记者；法律行动须实际授权，不能写成已报案 |
| S04 IPO传闻/信息泄露 | 核真假、公开状态、泄露范围、既有上市地义务；不默认否认或机械不予置评 | 项目负责人核状态；法务评披露；PR备确认已公开事实/有限回应/待核口径及内部联系纪律 | 回应不新增未公开敏感细节；应披露事项不能靠不置评延迟 |
| S05 现场检查/监管新增关注 | 区分随机、问题导向、督导与正式处理；看是否真实重大问题 | 保荐/业务/财务供证整改，PR组织公开解释和相关方问答 | 不把检查等同否决或保证无影响；有结论后更新 |
| S06 核心客户/关联依赖争议 | 核集中度、关联、客户财务独立性、替代与实际变化 | 业务和财务核客户结构、合同及收入；法务核关系；PR编集中度解释及客户沟通准备 | 不能以明星客户背书掩盖依赖，不能用未披露新订单救急 |
| S07 技术/专利/临床或商业化争议 | 区分技术判断、权属、性能证据、临床阶段、商业兑现 | 技术/医疗/法务提供原始依据；PR将宣传用语与招股书对照，删除无证据升级 | 争议未裁决不写胜诉；试验/样机不能写获批/量产 |
| S08 安全、劳动、数据或治理事件 | 优先实际损害、责任和持续风险；上市节点不削弱业务处理 | 对应业务/HR/法务处置，董办评披露；PR回应关切、提供已落实措施和下一更新 | 不以制度文本证明整改完成；人员隐私与事实调查分开 |

| S10 取消/暂缓/未通过审议或聆讯延后 | 区分排期与结果、已知理由与猜测 | 董办/保荐核事实；PR备分支口径和利益相关方沟通；重排节点任务 | 不承诺下次时间或通过；披露补充事项真实保留 |
| S11 撤回/终止/退回/失效/再申报 | 核各状态含义、历史问题、再报变动和证据 | 保荐/法务提供状态及允许表述；PR编时间线、差异表、问答 | 主动撤回不等“无问题”；港股失效不等否决；退回不等到期 |
| S12 定价争议/AH折价/摊薄 | 区分估值方法、股份类别、币种、盈利口径与市场 | 承销/财务提供公开参数；PR制作募资必要性及定价解释、敏感问答 | 不承诺公允收益或无摊薄；不能只挑最高同行估值 |
| S13 基石变动/认购冷热/延期发行 | 正式文件、认购口径和未授权订单簿分开；市场供给和基本面共同分析 | 承销接口核可公开事实；PR备不含未披露数据的口径、方案变更材料 | 不擅发退出原因/名单；锁定不保证未来不卖 |
| S14 暗盘/首日大涨或破发 | 区分暗盘平台与正式交易、样本和时点、流动性及发行因素 | PR监测问题，IR整理事实，备上市事实稿及表现Q&A | 不把涨跌当价值裁决，不暗示公司托底，不承诺后市 |
| S15 首份业绩/预期落差 | 对照招股文件已披露预测与实际、法定/调整口径、更新义务 | 财务/董办判断披露，PR解释经营变化、风险与下一验证点 | 不把不及分析师预期混同违反承诺；必要即时披露不等定期报告 |
| S16 稳定价格期结束/解禁衔接 | 核机制是否适用、合同与法规、实际日期、持有人及可流通比例 | IR/董办核结构；PR备供给变化、经营事实和股东行为区分材料 | 解禁不等实际减持，不承诺持有人不卖；转常态上市公司工作 |
| S17 A股赴港争议 | 既有股东、募资用途、跨市场披露、估值与治理相互作用 | 叠加hong-kong.md跨市场路径，制作两地事实对照与问答 | 非公开不构成信息豁免；两地口径一致且不混主体 |

## 判断回应强度

- 核实明确的事实错误：逐项提供证据请求更正，记录实际结果，不笼统要求撤文。
- 合理分析分歧：解释口径、背景和反证，承认判断空间，不要求改立场。
- 材料不足：列待核、核查动作及下一更新点，不拿未经核实的利好填空。
- 真实问题：治理/业务整改、披露评估、相关方沟通一起开展，说明已完成与计划。
- 投诉索财：独立保存证据，法律判断与事实回应分别推进。

# 参考资料采用原则

## 原始资料

本项目由IPO财经公关工作台的流程经验整理而成。公开包保留方法和模板，不附原始参考全文；其中未经独立核验的嵌套引用、统计与个案不作为事实依据。采用新资料时取得原文并记录可核出处，不要求使用者获取未公开的历史附件。

保留阶段—任务—交付结构、提前备答、媒体与内部跨部门协作、节点预案。增加内部PR默认与顾问模式、价值叙事、三线观察、不同板块与A股赴港、非线性进度、证据和验收。

## 修订与不默认采用项

| 原材料主张 | 处理 |
| --- | --- |
| IPO审核期一律法定静默 | 改为逐市场/主体/行为核宣传和披露；不据此全部禁言或全部放行 |
| 全程平均一年、上会委员七人五票等统一数字 | 本轮未完整核原文，不作确定操作依据；按板块现行规则查程序，实际日历单列 |
| 受理即检查，检查/撤单显示零容错 | 依据证监会2026-02-06通报区分检查类型和问题性质，不推断所有受理即检查 |
| 港股非公开是无干扰安全舱 | 去除保证；既有公开信息、传闻及投诉仍需处理 |
| 有效期12个月是非公开递表优势 | 更正为符合2026-08-21措施条件的申请适用，核期限/例外，不与递表方式捆绑 |
| 港股所有企业有黑函、媒体压力主要来自恶意攻击 | 作为待核行业说法，不预设动机；按具体投诉证据处理 |
| A股媒体是监管延伸，港股只重非财务风险 | 改为三线观察，各市场均分析经营财务与治理 |
| 自媒体85%、红筹2.4%、基石81.32%、破发率等 | 无可核原始样本/分母/期间，不作为当前统计引用 |
| 上市委前固定高峰、备案后一两周聆讯 | 作为待验证经验而非时间保证，按真实项目与样本调整 |
| 首日表现最终裁决定价合理性 | 改为短期交易观察，不作为长期价值或PR绩效裁决 |
| 按友好/不友好媒体分配独家信息 | 改为受众、专业度、证据质量和传播特征；未公开重大信息不换取报道 |
| 两小时控制扩散、撤稿和SEO压制 | 改为可验收的核查/响应目标、证据更正和正式信息可查 |
| 具体个案中的举报、案件编号与原因 | 未独立核实，不当已证实案例，不继承对相关个人或公司的指控 |

不要将原材料日期数字自动更新为当前年份。案例只支持其证据实际覆盖的结论；“媒体认为”“公司解释”“监管认定”分别标注。

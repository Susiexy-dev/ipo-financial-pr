# 项目诊断、职责与顾问模式

## 立项卡

一次提取可用信息，后续按任务补齐：
- 企业：法定名称/简称/曾用名、注册地、集团和发行人边界、产品与行业、现有上市状态。
- 路径：目标交易所、板块、上市标准、H股/红筹/双重或第二上市、特殊章节、公开材料安排、境内备案适用性。上市路线由企业与中介决策，PR提供受众与声誉影响评估。
- 状态：正式节点及证明、下个事件和可调整窗口、补材料/中止/撤回分支、审计期、财务资料有效期待核。
- 认知：公众已有印象、核心经营逻辑、主要争议、关键受众、预期差。
- 资源：负责人及发言人、保荐人/律师/审计/承销接口、语言、媒体、预算、人力及供应商覆盖。

给出当前最重要的待办。缺少公司数据时输出诊断问题和数据请求，不填虚拟经营指标。

## 六维诊断

| 维度 | 判断问题 | 证据与交付 |
| --- | --- | --- |
| 路径与节点 | 当前正式状态？公开范围？ | 状态证明、下一节点及依赖 |
| 经营与价值 | 谁付钱，为何选择它，增长如何兑现？ | 收入/利润/现金桥、行业对标 |
| 治理与披露 | 历史、关联、内控与业务资料有何矛盾？ | 问题、责任人和证据缺口 |
| 认知与争议 | 主张被谁接受或怀疑？ | 受众—问题—依据—回应矩阵 |
| 内容与触达 | 哪些材料和渠道能解决理解障碍？ | 主题、素材、渠道及节点 |
| 执行能力 | 谁能提供事实并做决定？ | 责任表、审定及备援 |

## 职责接口

| 工作 | 牵头岗位 | 协同/决定接口 |
| --- | --- | --- |
| 公关策略、记者沟通、认知台账 | PR负责人 | 董办/IR、业务、管理层 |
| 上市状态与正式披露协调 | 董办/上市项目负责人 | 保荐人、境内外律师、财务 |
| 财务指标和非准则指标解释 | 财务负责人 | 审计师、保荐人、PR |
| 技术、客户、订单证据 | 对应业务负责人 | 财务、法务、PR |
| 举报、争议及诉讼核查 | 按事项指定法务/HR/业务负责人 | 保荐人、律师、PR |
| 发行参数、路演及机构反馈 | 承销/资本市场接口 | IR、管理层、PR |
| 最终对外发布 | 企业实际授权岗位 | 相关专业审定人 |

岗位不等于个人；不编造姓名或已批准状态。危机时设唯一协调窗口，业务处置、证据核查、披露评估并行，不能等全套公关方案才启动。

## 整体方案

写清项目现状与约束、市场和同业环境、受众及认知问题、价值主张和争议解释、阶段任务与媒体策略、事件预案、组织资源预算及评价。将“多发稿”转成理解目标，如重点报道正确区分试用订单与确认收入。

倒排包含资料截止、首稿、财务/业务核对、法律及发行宣传核验、管理层预演、发布条件、执行及反馈。跟随真实状态重新排程；不用全流程平均耗时保证上市日期。

## 顾问模式

沿用事实与披露标准，增加：
1. 客户诊断：问题、目标、现有材料、可调用资源与基线。
2. 服务范围：交付物、数量/迭代轮次、语言、周期、覆盖时段、第三方成本。
3. 客户输入：招股书版本、经营数据、发言人、审定人、反馈时限。
4. 变更：延期、撤回、再递表、增加语言/活动、突发事件如何调整交付与费用。
5. 验收：准确性、按时率、可用性、真实触达与认知反馈；不保证媒体立场、监管结果或股价。

预算字段：项目/计算依据/数量/单价来源/税费与币种/第三方支出/假设/上限/负责人/验收证据。无询价不给“市场标准价”，可给待报价结构或注明假设的方案。媒体商业合作与编辑沟通分开，不售卖删稿或独立正面报道承诺。

# 企业价值叙事与证据

## 从招股书到可理解的企业

先读取业务、行业、财务、风险、历史及股权、关联交易、募投等相关章节，标注版本与期间。不要只看摘要或复制行业顾问的市场排名。针对任务选择深度，避免为了写短稿无边界读全库。

组织六个问题：
1. 谁在为什么付钱？产品、付费方、使用场景、收入确认及复购。
2. 为什么选择这家公司？可比较的产品/技术/成本/渠道/交付能力及限制。
3. 增长来自哪里？数量、价格、产品组合、新客户、周期、并购或一次性因素。
4. 增长质量如何？毛利、费用、经调整利润、应收、存货、经营现金和资本开支。
5. 哪些风险影响持续性？客户/供应商依赖、关联、知识产权、监管、治理和资金。
6. 募资后什么将改变？用途、投入路径、里程碑与不确定性，不承诺达产或收益。

## 主张—证据矩阵

每项核心主张列：面向受众、精确表述、证据ID、反向证据/限制、可比对象、公开状态、确认岗位、下一验证点。优先选择能支撑的少数主张，证据薄弱时降级表述。

| 常见主张 | 核查 | 可用表达条件 |
| --- | --- | --- |
| 行业领先/第一 | 市场边界、指标、地区、期间、报告资助及独立性 | 带排名口径与来源，不扩大细分市场到全行业 |
| 核心技术/自主可控 | 技术来源、专利权属、量产验证、关键外购依赖 | 技术指标对应真实客户价值，承认边界 |
| 高增长 | 基数、收入确认、一次性及关联贡献、周期影响 | 描述实际数据，增长不直接推导持续性 |
| 商业化突破 | 试用、框架、订单、交付、验收、收入/回款 | 逐层说明，不从意向协议跳到业绩 |
| 盈利改善 | 法定/经调整口径、剔除项、可重复性、现金 | 给调整桥；不把公允价值收益视作经营现金 |
| 国际化 | 海外收入、客户、交付、实体、政策与汇率风险 | 签约或参展不等于形成规模海外业务 |
| 知名股东/基石 | 主体、关系、入股期/金额及公开范围 | 陈述事实，不替机构发言或承诺回报 |

## 行业适配

- 科技、AI、机器人：研发到收入的路径、单价/销量、软硬件收入、订单口径、交付良率、客户复用、现金消耗、知识产权和数据来源。样机展示不当量产；集团能力不当发行人收入。
- 医疗及生物科技：研发/注册/临床阶段与商业销售分开，适应证及审批地区、证据质量、现金跑道、合作里程碑、支付及渠道。不得由早期试验推导有效性或必然获批。
- 制造及供应链：产能/产量/利用率、价格与毛利、客户集中、账期、存货、原料周期、扩产经济性和海外交付。
- 消费和服务：客单、客流/客户数、复购、单店/单客经济、加盟/直营、获客成本、收入净额/总额及退货。
以上为分析问题，不预设行业结论；有用户行业时再补原始行业数据。

## 叙事与争议同时设计

提出价值主张时同步写最强合理反问。例如“大客户验证技术”同时回答集中度、关联关系和可复制性；“研发投入领先”同时回答成果、费用口径和现金承受力。不得用宏大行业前景覆盖真实治理或财务问题。

素材形成四层：一句定位；一页经营事实；带证据的业务解释；管理层难题回答。面向内部可讨论假设，面向公开只用满足披露及宣传条件的信息。中英文保持同一事实，不在英文版新增预测或更强确定性。
